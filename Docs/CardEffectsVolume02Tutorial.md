# 從零開始：Blender 5.1.2 → ChessRPG / Unity 6

這份練習配合本資料夾的 `ChessRPG_FX_Volume02.blend`。先做會轉的光環，再改成自己的卡牌特效。第一輪約 30–45 分鐘；不需要先學完整建模。

## 介面閱讀方式

本教學以你目前 Blender 5.1.2 的「繁體中文」翻譯為準。Blender 有些用詞和平常不同：「算繪」就是渲染畫面，「空體」是沒有外形、用來帶動其他物體的控制物體，「力量」在發光設定中就是亮度強度。

Unity 的內建翻譯可能因語言套件而不同；下面用中文解釋，括號保留需要尋找的英文。ChessRPG 自己寫的選單、程式欄位、檔名不會隨介面語言自動翻譯，所以會保留實際名稱並附中文意思。

先認識 Blender 的四個區域：

- **中央大區域：3D 視窗**，用來看模型、選取和移動物體。
- **右上方：大綱編輯器**，像資料夾清單，列出場景中的物體。
- **右下方：屬性編輯器**，左邊直排小圖示可切換材質、曲線、輸出等設定。
- **下方：時間軸**，有播放按鈕和影格數字，用來製作動畫。

找不到面板時，先確認有選到正確物體。例如只有選到曲線，右側才會出現綠色曲線圖示。

## 1. 先看完成品

Blender：「檔案 → 開啟」，開啟本資料夾的 `.blend`。滑鼠移到 3D 視窗按空白鍵，播放／停止。這是造型展示，四款都循環展示；Unity 中火球與祝福是單次淡出。

Unity：選單 **Tools（工具）→ Chess（西洋棋）→ Presentation（演出）→ Spell Effects 02（第二組卡牌特效）→ Play Preview（播放預覽）**。預覽中火球與祝福每三秒重播，回春與詛咒持續播放。結束請再按上方的 ▶ 播放按鈕，回到原本棋盤。

| 卡牌 | 預製物件檔名 | 演出 | 何時出現 |
|---|---|---|---|
| E04 火球 | EmberBurst | 橘紅火舌與碎環，約 1.5 秒淡出 | 造成傷害時 |
| E02 祝福 | BlessingStar | 金色六芒星與光冠，約 1.5 秒淡出 | 治療時 |
| E10 回春 | RenewalLeaves | 綠色雙螺旋藤葉，4 秒循環 | 第一項狀態生效期間 |
| E05 詛咒 | CurseChains | 紫色鎖鏈與地面符文，4 秒循環 | 第一項狀態生效期間 |

Unity 素材在 `Assets/Art/VFX/CardSpells02`；獨立場景是 `Assets/Scenes/Previews/CardSpells02Preview.unity`。

## 2. 你在製作哪幾件事？

- **形狀**：光環、星形、火舌。Blender 的「網格」或「曲線」負責。
- **材質**：形狀的顏色、透明、發光。Blender 與 Unity 各有自己的材質系統。
- **動作**：旋轉、浮動、變大、消失。Blender 可以用關鍵影格，Unity 可以用動畫控制器（Animator）或程式。
- **粒子**：大量小火花、煙、光點，由 Unity 的粒子系統 發射。
- **預製物件（Prefab）**：Unity 將以上物件存成可以重複生成的一包資產。

本次是可編輯的線條特效原型，不是寫實火焰模擬。先掌握形狀、節奏與生命週期，再加入煙霧貼圖或更精細的粒子。

## 3. Blender 必會操作

| 操作 | 快捷鍵 |
|---|---|
| 選物件 | 滑鼠左鍵 |
| 旋轉觀看角度 | 按住滑鼠中鍵拖曳 |
| 平移觀看角度 | Shift + 中鍵 |
| 縮放觀看角度 | 滾輪 |
| 移動／旋轉／縮放物件 | G / R / S；接 X、Y、Z 可鎖定軸 |
| 確認／取消操作 | 左鍵或 Enter／右鍵或 Esc |
| 正面／側面／頂視圖 | 數字鍵盤 1 / 3 / 7 |
| 聚焦選取物件 | 數字鍵盤小數點；或 「檢視 → 聚焦視窗中的選取物」 |
| 新增／複製 | Shift+A / Shift+D |
| 物件模式與編輯模式切換 | Tab |
| 復原／另存新檔 | Ctrl+Z / Ctrl+Shift+S |

快捷鍵取決於滑鼠所在區域。做模型時，先把滑鼠放進 3D 視窗。「物體模式」改整個物體；「編輯模式」改頂點或曲線控制點。

## 4. 第一個練習：旋轉光環

先另存 `MyFirstCardFX.blend`，避免蓋掉範例。也可以 「檔案 → 新增 → 通用」，從空白場景練習。

1. 選取預設立方體，按 X 並確認刪除。按 Shift+A →「曲線 → 圓」，新增圓形曲線。
2. 右下方屬性編輯器，點「綠色曲線圖示」→「幾何 → 倒角 → 深度」 設 `0.02`。原本沒有厚度的線就變成細管。
3. 按 S，輸入 `0.4`，Enter。這是約半徑 0.4 的光環；接著 3D 視窗上方選單「物體 → 套用 → 縮放」，固定尺寸。
4. 按 Shift+A →「網格 → UV 球體」新增記號。按 S、輸入 `0.05`、Enter，再按 G、X、輸入 `0.4`、Enter，將它移到圓環外側。完整圓環旋轉時看不出差異，所以需要這個記號。
5. 按 Shift+S → 選擇將游標移到世界原點的項目，再按 Shift+A →「空體 → 純軸」，命名 `FX_Root`（意思是特效的總控制物體）。先選圓環，按住 Shift 加選記號，最後加選空體，按 Ctrl+P →「物體 (保持變換)」。這是建立父子關係；之後只轉空體，整組一起動。
6. 選圓環，在右下方點「材質屬性」（球形圖示）→「新增」。在「表面」的「原則化 BSDF」設定中展開「發光」，「色彩」選綠色、「力量」設 `3`。原則化 BSDF 是預設材質的名稱，現在不用背。記號可從材質下拉選單選同一份材質。3D 視窗右上有四個球形顯示按鈕，選「材質預覽」或「算繪」；滑鼠停在按鈕上可看到名稱。
7. 選 `FX_Root`，在下方時間軸將目前影格設 `1`。滑鼠放在 3D 視窗按 N，右邊會展開側欄，選「項目 → 旋轉」，Z 設 `0`。滑鼠停在「旋轉」數值欄位按 I，記錄這一格的角度；這個記錄叫「關鍵影格」。
8. 影格設 `97`，Z=`360°`，再在「旋轉」欄位按 I。右下方「輸出屬性」（印表機圖示）的「幀率」設 `24 fps`，意思是每秒 24 格。「開始」設 `1`、「結束」設 `96`，也可在時間軸上設定起訖格數。
9. 點下方時間軸最左側的「編輯器類型」圖示，切換成「圖表編輯器」。選取這組旋轉關鍵影格，滑鼠停在圖表區按 T →「線性」，避免開頭加速、末尾減速。播放 1–96 是四秒一圈；97 是下一圈的重複端點，所以不包含在播放範圍。
10. 按空白鍵播放。試著把第 97 格改成 `-360°`，觀察方向；把它移到第 49 格並改「結束」為 `48`，觀察速度。

完成標準：記號均速繞圓一圈，重新播放沒有明顯停頓。

提供的檔案另有隱藏集合 `LESSON / reveal to practice`，裡面的 `LESSON_Rune` 已有第 1、97 格旋轉關鍵影格。這兩個英文是檔案內保留的物體名稱，分別代表「練習集合」與「練習符文」。可在右上方「大綱編輯器」開啟集合顯示後練習。若找不到控制顯示的監視器圖示，點大綱右上方漏斗形的「過濾器」按鈕，啟用監視器欄位。展示區其他物體使用「驅動器」（用公式控制動畫），初學時先練這個符文或自己新建的總控制物體。

**發光顏色不等於畫面上的光暈。** 「發光」決定物件發出的顏色；柔亮外擴的光暈是後製。Blender 5.1 可在 「合成」工作區的「算繪分層」與「合成」節點之間加入「耀光」節點，類型使用「霧發光」。先按 F12 看渲染；不要找舊版教學中的 Eevee Bloom 勾選框。

## 5. 把形狀匯入 Unity

先用現成四個 `.fbx` 練習：拖進 Unity 的「專案」視窗（Project，放素材的資料夾區），再拖到「場景」視窗（Scene，放物體的畫面）。它們只包含特效形狀，不含展示棋子與底座；**它們是靜態模型，不會自己旋轉或發光**。

自己匯出時：

1. 另存 Blender 檔，保留可編輯的曲線版本。
2. 複製要匯出的曲線，在「物體模式」使用上方選單「物體 → 轉換 → 網格」。只轉複本。
3. 選特效模型及必要的父物件。「檔案 → 匯出 → FBX」，勾「選取的物件」，「前進」設負 Z 方向（`-Z Forward`）、「向上」設 Y 方向（`Y Up`）。
4. 只要靜態模型就關閉「烘焙動畫」（Bake Animation；你這版可能仍顯示英文，意思是把動作逐格記錄到匯出檔）。本課附送的四個 FBX 採這個方式。
5. 如果要輸出自己做的關鍵影格動畫，選取已動畫的空體及子物件，啟用「烘焙動畫」（Bake Animation），檢查輸出起迄範圍。匯入 Unity 後，點選模型，在右側檢視器（Inspector）的「動畫」（Animation）分頁確認有「動畫片段」（Clip），依需要勾「循環時間」（Loop Time），再用動畫控制器（Animator）播放。

FBX 可以帶網格、貼圖座標（UV），以及支援的逐格記錄動畫；Blender 的材質節點、驅動器、幾何節點 與後製效果不會直接變成 Unity 特效系統。匯出前仍需檢查大小、方向和動畫。

Unity 材質練習：在專案素材區按右鍵 →「建立」（Create）→「材質」（Material）。在右側「著色器」（Shader，決定物體怎麼顯示）選 `Universal Render Pipeline/Lit`，這是需要照著選的實際項目名稱。啟用「自發光」（Emission），挑綠色並提高 HDR 色彩亮度，再把材質拖到模型上。「光暈」（Bloom）要在 URP 的後製設定物件（Volume）裡設定，而且相機需開啟後製。URP 是這個 Unity 專案使用的繪圖系統；自發光不會自動照亮旁邊棋子。

## 6. 這次成品如何進 Unity？

為了保留可改線寬、旋轉和顏色的能力，成品預製物件使用 Unity 的**線條渲染器（LineRenderer，將一串點畫成線）**。Blender 建置腳本另輸出 `CardFXVolume02.json`，保存線條頂點；專案的 `CardFXVolumeTwoSetup` 再用這份資料建立預製物件。這是本範例的專用轉換工具，不是 FBX 自動轉換功能。

- `CardIdleEffectMotion`：旋轉／浮動、四秒循環，依棋子尺寸調整。
- `CardSpellPulse`：單次演出漸顯／淡出，約 1.5 秒後銷毀。
- `IdleLines.mat`：沿用第一組的加色透明材質。

雙擊一個預製物件檔案，展開 `Editable outlines`（可編輯線條），選其中的線條物體，在右側線條渲染器設定顏色漸層與寬度（Color／Width）。先用 Ctrl+D 複製資產再改。調整最外層物體上的 `CardIdleEffectMotion` 元件：「Loop Seconds」（每圈秒數）可改速度、「World Radius」（實際半徑）可改寬度；不要把一組特效放大到蓋住附近格子。

如果從 FBX 自己製作，則使用「網格渲染器」（MeshRenderer，顯示模型的元件）配自己的材質與動畫控制器即可，不需要轉成線條渲染器。完成後將最外層物體從「階層」（Hierarchy，場景物體清單）拖到「專案」（Project，素材資料夾區），儲存為預製物件。

## 7. 加入第一組粒子（可選練習）

在自己的特效根物件底下按右鍵 →「特效」（Effects）→「粒子系統」（Particle System），材質使用 URP 相容的粒子材質和透明光點貼圖。先用以下數值感受效果：

| 設定 | 待機光點 | 單次火花 |
|---|---|---|
| 持續時間（Duration，秒） | 4 | 1 |
| 循環播放（Looping） | 開 | 關 |
| 粒子存活時間（Start Lifetime，秒） | 1.5 | 0.6 |
| 初始速度（Start Speed） | 0.2 | 1 |
| 初始大小（Start Size） | 0.03 | 0.04 |
| 發射模組 → 每秒發射數（Emission → Rate over Time） | 8 | 0 |
| 發射模組 → 瞬間發射（Emission → Bursts） | 無 | 時間（Time）=0、數量（Count）=8 |
| 模擬空間（Simulation Space） | 本地（Local） | 先用本地（Local） |

「本地」（Local）讓光點跟著棋子移動；「世界」（World）會留在已發射的位置。循環光點可勾「預熱」（Prewarm），讓出現時已有粒子；預熱需要開啟循環播放。單次粒子播完不代表整個遊戲物體自動消失，還要設定「停止動作」（Stop Action）或由卡牌程式清理。

## 8. 掛到 ChessRPG 卡牌

在 `Assets/Resources/Cards` 選卡牌資產，不是選場景裡的卡牌圖片。

**持續狀態**：E10、E05 的 「Definition」（卡牌定義）→「Statuses To Apply」（要套用的狀態）→ 第一項 →「Idle Effect Prefab」（狀態持續時的特效預製物件）。狀態套用時生成，棋子移動時跟隨，狀態解除時停止。

**單次演出**：E04、E02 的 「Definition」（卡牌定義）→「Animations」（演出清單）新增一項，按下表設定。這些是專案自訂欄位，因此保留畫面上實際的英文名稱：

| 畫面上的欄位 | 中文意思 | 要填的內容 |
|---|---|---|
| Effect Prefab | 使用哪個特效 | 拖入對應的預製物件 |
| Timing | 何時播放 | 火球選 OnDamageDealt（造成傷害）；祝福選 OnHealed（治療） |
| Recipient | 哪一方接收演出 | Both（雙方） |
| Attach Effect To Receiver | 特效跟隨接收的棋子 | 勾選 |
| Effect Scale | 特效縮放 | X、Y、Z 都填 1 |
| Effect Lifetime | 特效存在幾秒 | 1.6 |

以上數值使用本次成品的設定。

這個專案的事件卡可能讓 來源與目標是同一棋子；「雙方」（Both）能接到這種通知。祝福的治療流程這次補上「治療時」（OnHealed）通知，治療數值未修改。

**專案還需要場景樣板登記**：`SceneObjectTemplates`（場景物體樣板庫）透過來源預製物件欄位（sourcePrefab）對應場景內模板。這次的兩個單次特效已透過工具加入目前棋盤，且預覽場景已存檔。當前棋盤原本有未儲存修改，因此保持未儲存；停止播放、回到編輯狀態 確認後按 Ctrl+S，才會把這次新增的登記一起寫入場景。若在另一個棋盤場景使用相同兩款特效，執行 **Spell Effects 02（第二組特效）→ Register Active Scene（登記到目前場景）** 再存場景。

新增其他單次特效時，也要在場景物體樣板庫（SceneObjectTemplates）加入一筆項目（Entry）：來源預製物件（sourcePrefab）是卡牌引用的特效檔，模板（template）是不會在場景中直接播放的模板物體，識別名稱（key）不能和其他項目重複。本次工具只負責 EmberBurst／BlessingStar。

改卡牌資產後請按上方 ▶ 按鈕停止遊戲播放 再重新播放，讓卡牌定義重新載入。

## 9. 常見問題

- **物件變粉紅色**：材質使用的著色器（Shader）不適合專案的 URP 繪圖系統，換成專案相容 Shader。
- **沒有光暈**：先確認「發光」，再確認相機後製與後製設定物件的光暈效果；Blender 的「實體」顯示模式不能代表最終算繪。
- **很大／很小**：先看匯入時的縮放、模型的變換設定與父物體縮放。現成預製物件以「World Radius」（實際半徑）調整。
- **轉一圈卡一下**：旋轉關鍵影格改「線性」；不要把重複的端點多播放一次。
- **可以預覽但出牌不播放**：查播放時機（Timing）、接收對象（Recipient）、卡牌使用的特效檔，以及場景樣板庫的登記。
- **狀態消失後特效仍在**：確認交由狀態特效欄位（Idle Effect Prefab）管理，不是手動放進棋子卻沒有清理。
- **看不到火球／祝福**：預覽每三秒重播，兩次之間會有空檔；實際對局只在事件發生時播放。

原始卡牌及 CardBattleSystem 備份在本資料夾 `Backup`。不要在後續已修改專案時直接覆蓋備份，先比對差異。
